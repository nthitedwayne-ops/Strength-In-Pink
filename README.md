# Strength In Pink— Breast Cancer Awareness Website

A responsive static website starter for a South African breast cancer awareness project.

## Files
- `index.html` — content and page sections
- `styles.css` — responsive styling
- `script.js` — mobile navigation, current year, and share button

## Preview locally
1. Extract the ZIP.
2. Open `index.html` in a modern browser.
3. For local hosting, use VS Code Live Server or upload the three files to your hosting `public_html` folder.

## Before publishing
- Confirm the organisation name and permission to use it.
- Verify CANSA contact details and links before launch.
- Replace illustrative emoji/abstract art with approved campaign imagery if desired.
- Add your real contact details and privacy notice if collecting personal information.
- This is a static site; it does not yet include a database, admin dashboard, or contact-form backend.
- Medical content is general awareness information, not a diagnosis or treatment recommendation.
